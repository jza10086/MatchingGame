# 连连看

1–8 人的 3D 连连看。单人限时清空棋盘；多人争抢同一棋盘，主机先收到的有效消除请求得 1 分，同分并列。

全幅透视棋盘，沿用记忆拼图的薄方块棋子、顶面贴图、暖色边缘与平滑抬升做法；棋子缩小到 0.94×0.94，厚度 0.14，选中时轻抬 0.14。十种水果使用包内现有 SVG 贴图，不生成水果立体模型，也不依赖拼图包。鼠标射线拾取棋子；布局随窗口缩放，保留外圈路径空间。棋盘规则仍在二维格点上判定。画质由原版协议公共设置统一管理。

局内仅在右下角显示操作提示：左键选择/配对，再次点击取消；右键放下选中棋子；中键使用私密提示。Esc 临时展开框架菜单，菜单打开时禁止棋盘输入，比赛计时继续。移除局内标题、计时/计分侧栏和说明面板；最终成绩仍由协议结算页显示。

默认 180 秒、8×10 共 40 对。最多两个转弯，允许走外圈。每人默认 3 次私密提示；共享棋盘只在无解时自动重排，不提供个人手动洗牌。已被别人消除的配对不能重复得分；不冲突的配对不因其他人的消除而失效，重排才使旧代请求失效。清空棋盘或超时结算。原版协议鼠标组件使用玩家颜色和名字显示位置，不占用点击、不参与裁定，断线/离开棋盘/超时后隐藏。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

验证脚本与输出放在主工程 tmp/test/matching_3d/。已自动验证正式大厅的单人及双端 ENet 准备、射线点选、私密提示、40 对清盘和轮换成绩提交；轻抬/放下、Esc 菜单的输入隔离与设置返回、退出子局后恢复工具栏通过。重排后的选中/提示/路径清理与旧请求拒绝，以及 1080p、1440p、4K、超宽屏的拾取、外圈布局和归一化指针位置检查通过。已检查全幅透视贴图棋盘的单人运行截图。旧 original_arcade 测试已退役归档，不作为当前验收依据；8 人实测、真实键鼠、多窗口手感及外网仍需人工检查。
