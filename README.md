# 果园连线 · Matching Game

独立 Godot 4.7.2 **经典连连看**小游戏，不是翻牌记忆游戏。清新果园主题，10 种原创水果图标，8 行 × 10 列，共 40 对。

## 运行

用 Godot 4.7.2 打开 `project.godot`，按 **F5**。推荐键鼠；最低窗口 960 × 640，默认 1280 × 800。GL Compatibility 渲染器。项目是编辑器源码，不是 Windows EXE，也没有 AI 或联网模式。

## 规则与操作

- 点击两个相同图案；路线必须水平或竖直，**最多转弯两次**，不能穿过未消除的图块。
- 允许沿棋盘外侧的一圈空位绕行，路径会直接显示。
- 点击已选图块取消；无法连接时，第二颗成为新的选择。
- H /「提示」：高亮一对当前可连图块并显示路径，不消耗或消除图块。
- S /「洗牌」：重新排列剩余水果，保留水果数量及已清空的位置，生成可解布局。
- R /「重新开始」：弹窗确认后清空进度，取消则保留当前局。
- 方向键移动键盘焦点，Enter / Space 选中；Escape 取消选择。
- 「减少动态」关闭悬停缩放及消除缩小效果，保留简短静态路线反馈。
- 无倒计时惩罚；计时仅供参考，重新开始弹窗期间暂停计时。

消除时显示连线绘制与图块收缩动画；动画期间重复输入不会重复扣除。全部消除后显示用时，并可再来一局。

## 有解性与死局

初始布局及每次洗牌都会先构造几何上可逐对移除的位置序列，再把成对水果分配给这些位置，保留一份完整可验证的解题序列。初始局和洗牌结果因此至少有一种解法。

玩家可以选择别的合法消除顺序，**不承诺所有任意选择都永不死局**。剩余图块无可连接对时自动洗牌；提示也会检测并恢复死局。洗牌不增加已消除数量，也不会把空洞填回来。

## 结构

- `scripts/matching_rules.gd`：纯规则、路径查找、有解生成、提示、洗牌。
- `scripts/main.gd`：棋盘 UI、键鼠输入、连线、动画与状态。
- `assets/icons/`：10 种原创矢量水果图案。
- `assets/fonts/`：Noto 中文字体与 SIL OFL 许可。
- `ART_SOURCES.md`：素材来源和归属。
- `tests/`：核心与独立审查测试、原生渲染截图脚本。
